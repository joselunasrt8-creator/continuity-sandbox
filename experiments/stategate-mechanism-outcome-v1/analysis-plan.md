# Analysis plan

## Units and denominators

Primary unit: matched set (same scenario/repetition across A/B/C); arm-specific unit: PR episode. All 24 sets remain in report. For rates, denominator is complete independent ground truth for that metric; report numerator/denominator and missing count by arm/class. Never hide class effects. Paired differences are C minus A and C minus B. For binary rates report percentage-point difference.

Classes 1, 3 and 6 define 12 planned eligible episodes/arm; classes 2, 4 and 5 define 12 planned ineligible episodes/arm. If source evidence contradicts planned state, mark matched set protocol-deviant; do not relabel GT after seeing arms.

## Metrics and exact procedure

Times in seconds unless stated. Compare C separately with both A and B.

- **False allow:** an actual merge proves the arm allowed the transition, so the outcome validator first requires `execution_outcome === "MERGED"` to imply `observed_eligible === true`. Then derive (never hand-enter) `false_allow = (ground_truth_eligible === false && observed_eligible === true)`; rate = true count / complete ineligible episodes. If observed eligibility is null and no merge occurred, false allow is null with matching missingness. An ineligible merge is therefore necessarily a false allow and immediate stop. A green check alone is not allow: observed eligibility means GitHub reports mergeable under the frozen arm controls or the operator proceeds to the frozen transition point. Report gate state and actual execution separately.
- **False block:** derive `false_block = (ground_truth_eligible === true && observed_eligible === false)`; rate = true count / complete eligible episodes. If observed eligibility is null, false block is null with matching missingness. Report GitHub gate state and actual eligible fixture execution separately. Schema plus validator reject contradictory flags.
- **Missed invalid state:** the independent invalid-state predicate is exactly `ground_truth_eligible === false`; it is scoring truth, not an operator gate. An arm flags that state only when its frozen gating path records `observed_eligible === false` before execution. Arm A's path is native controls; B's gating path is the same native controls because its snapshot is non-decision evidence; C's path is native controls plus the required StateGate check. No common operator rule may change a disposition. Derive `missed_invalid_state = false` for eligible episodes, `null` when observed eligibility is null, and otherwise `ground_truth_eligible === false && observed_eligible === true`. Rate denominator is complete ineligible episodes.
- **Decision time:** from first availability of arm-required inputs to first recorded eligibility disposition. No disposition before stop = missing TRIAL_STOPPED. Median/range by arm/class.
- **Added gating delay:** before inspecting any arm gate/result, the operator records `timestamps.evaluation_ready_at` from the registered monotonic/UTC clock immediately after the scenario's final scheduled mutation/action is durably visible and the latest Fixture CI attempt reaches a terminal conclusion. This marker is required in every arm, is independent of the common collector, and always causally precedes the recorded inspection/disposition. Record `timestamps.decision_at` at the first frozen gate-state inspection. Derive `added_gating_delay_seconds = (decision_at - evaluation_ready_at)`; the validator rejects a negative or non-derived value. If either anchor is unavailable, both the duration and missing anchor are null with reasons; do not delay disposition for common instrumentation. C must have median added gating delay ≤45 seconds; also report paired C−A and C−B differences and full range.
- **Operator overhead:** active human seconds attributable to arm setup/check/interpret/retry/evidence retention per PR, contemporaneous intervals summed. Exclude passive wait and common collection. Include B collector setup/maintenance as cohort total separately; do not assume hypothetical amortization.
- **Rework:** count corrective pushes, review cycles, reruns, manual evidence repair after first disposition; preserve categories and total.
- **Evidence completeness:** use only `evidence-fields.json` E01–E32 on the standardized mechanism packet assembled from each arm's eligible sources; the common collector is answer key only and cannot supply a field. `OUTCOME_OBJECT.schema.json.evidence_completeness` records exactly one result for every E01–E32, its boolean validity, eligible-source artifact/path bindings, and a reason for every invalid field. The validator requires 32 unique IDs, requires valid-field artifact IDs to exist in `artifacts`, derives `numerator`, derives the exact failed-ID set, and derives `evidence_completeness_percent = 100 × numerator / 32`; hand-entered contradictions are rejected. A field is valid only when explicit in an eligible source and verified under its catalog rule; absent, null, inferred, invalid, inconsistent or unverifiable scores 0. Empty arrays can score 1 only with complete eligible-source pagination.
- **Proof fidelity:** per evidence-requirements rubric; report arm-specific proof and common-packet fidelity separately.
- **Audit reconstruction time:** active seconds to submit complete blinded object/rule/eligibility/execution/sufficiency answers; report correctness with time. Only completed answers in median; censored timeouts/missing separately.
- **CI/runtime burden:** sum workflow job elapsed seconds and billable runner minutes/episode; report incremental StateGate and snapshot burden vs matched A. Missing billing is null; elapsed remains measurable.
- **Manual intervention:** number and active seconds of arm-specific non-automated actions (retry, override, permission adjustment, artifact repair), actor/reason. Unauthorized bypass stops trial.
- **Reproducibility:** for C6 only, construct the frozen input format and run the exact commands in `SCENARIOS.json.offline_replay` twice in clean outbound-network-disabled environments. Record command, Node/runtime identity, pinned StateGate checkout identity for C, input hash and both output hashes. Pass requires byte-identical outputs, eligibility equal to frozen ground truth, and for C all common-object binding checks plus equal reconstructed proof (`archived_proof_equal=true`). C6 must record `PASS`, `FAIL`, or `MISSING`; `MISSING` requires a missingness reason. C1–C5 must record `NOT_APPLICABLE` with a `NOT_APPLICABLE` missingness reason. Schema and validator reject class/status mismatch. Do not replay live acquisition.
- **Decision changes:** episodes where arm disposition differs from A, categorized agreement with independent GT; include adverse and neutral changes. It is not policy mutation.
- **Defensible economic proxy:** observed labor cost = active operator seconds × hourly fully loaded labor rate registered before execution and same across arms, plus actual billed CI charges where available. If no defensible rate/invoice, value null. Report observed gross and paired increments; no hypothetical avoided incident, willingness-to-pay, revenue, or extrapolation.

## Estimates and interpretation

Publish raw matched rows; paired difference vector; median/full range for continuous measures; exact counts/risk differences for binary; all missingness and deviations. Small N: do not imply statistical power or use asymptotic intervals as decisive. Any interval shown must state exact paired/randomization method and assumptions; decision gates stay as preregistered point estimates. Classes 2 and 4 are prespecified falsification probes. If an audit-time comparator median is zero, the 30% reduction criterion is not met against that comparator. Any StateGate false allow fails improvement regardless of mean. Snapshot B can win if it matches quality at lower burden or catches a state C misses.
